# SalesFlow CRM Presentation

Client-facing presentation for a generic Sales CRM solution.

## How to Open

Open `index.html` in Chrome or Edge.

## Controls

- Next slide: right arrow, space, or `Next`
- Previous slide: left arrow or `Previous`
- Export as PDF: click `Download PDF` — the file `SalesFlow-CRM-Presentation.pdf` will download automatically (17 landscape pages, one slide per page)

## Files

- `index.html` - slide content
- `styles.css` - presentation design
- `script.js` - slide navigation
- `assets/` - screenshots and logo used in the deck
